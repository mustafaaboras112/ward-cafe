# كافيه ورد - دليل التشغيل

## المتطلبات
- متصفح حديث: Chrome, Edge, Safari أو Firefox
- اتصال بالإنترنت (يُستحسن) عشان يتزامن بين الأجهزة

## التشغيل المباشر بدون إعدادات
افتح الملف `menu/index.html` في المتصفح. المشروع يعمل محلياً فوراً.

## ربط قاعدة البيانات (Firebase)
1. افتح ملف `firebase-config.js`.
2. تأكد من أن القيم موجودة.
3. فعّل في Firebase Console:
   - Realtime Database
   - قواعد البيانات → Rules → اجعلها `true` للتجربة
4. بعدها كل الطلبات والمنيو والمحاسبة تتزامن بين كل الأجهزة تلقائيًا.

## ملاحظات
- إذا لم يكن هناك إنترنت، المشروع يكمل العمل محلياً (`localStorage`).
- بعد إعادة الاتصال، البيانات تتزامن مع Firebase تلقائيًا.
- رمز دخول لوحات التحكم: `1234`
