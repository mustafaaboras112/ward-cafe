# كافيه ورد

نظام محلي بسيط لإدارة كافيه صغير أو متوسط.

## الصفحات

- `login.html` — دخول الموظف بواسطة PIN فقط.
- `admin.html` — المنيو والموظفون.
- `pos.html` — الكاشير والطاولات والدفع والطباعة.
- `kitchen.html` — طلبات المطبخ وتحويل الطلب إلى جاهز.
- `waiter.html` — الطلبات الجاهزة والتوصيل ونقل الطاولة.
- `accounting.html` — مبيعات اليوم والمصروفات والتقرير وإغلاق اليوم.
- `index.html?table=1` — منيو الزبون وطلب QR للطاولة.

## التقنية

- Node.js + Express
- MySQL عبر XAMPP
- واجهات HTML/CSS/JavaScript محلية
- لا يوجد Firebase في النسخة الحالية

## الدخول

كل موظف يدخل بواسطة PIN من 4 إلى 8 أرقام. المدير ينشئ الموظفين ويحدد الدور والرمز من لوحة الإدارة.

الصلاحيات الأساسية:

- مدير: الإدارة وباقي صفحات الموظفين.
- كاشير: الكاشير والجرسون.
- محاسب: المحاسبة.
- جرسون: شاشة الجرسون.
- مطبخ: شاشة المطبخ.

## التشغيل السريع

1. شغّل MySQL من XAMPP.
2. تأكد من وجود قاعدة `ward_cafe` والجداول.
3. افتح PowerShell داخل `server`.
4. أول مرة فقط:

```powershell
Copy-Item .env.example .env
npm install
```

5. شغّل الخادم:

```powershell
npm start
```

6. افتح:

```text
http://localhost:3000/login.html
```

لإعداد قاعدة جديدة من الصفر راجع `server/README-XAMPP.md`.

## الاختبارات

من داخل `server`:

```powershell
npm test
```

مصدر البيانات الرسمي هو MySQL. العمليات الحساسة مثل الدفع وإغلاق اليوم وتغيير حالة الطلب تتم على الخادم.
