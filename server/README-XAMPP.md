# تشغيل كافيه ورد على XAMPP وMySQL

هذه النسخة تعمل على جهاز رئيسي داخل المقهى يشغّل MySQL وخادم Node.js. بقية الأجهزة تفتح النظام من المتصفح على نفس الشبكة المحلية.

## المتطلبات

- Windows 10 أو 11
- XAMPP مع MySQL/MariaDB
- Node.js 20 أو أحدث

## 1. تجهيز قاعدة البيانات

1. شغّل MySQL من XAMPP.
2. افتح phpMyAdmin.
3. أنشئ قاعدة باسم `ward_cafe`.
4. ادخل إلى قاعدة `ward_cafe`.
5. من **استيراد** نفّذ `server/sql/schema.sql`.
6. من **استيراد** نفّذ `server/sql/seed.sql`.

لا تكتب مسار الملف داخل مربع SQL؛ اختر الملف من تبويب استيراد.

## 2. إعداد الخادم

افتح PowerShell داخل مجلد `server`:

```powershell
Copy-Item .env.example .env
npm install
```

إذا كانت القاعدة جديدة ولا يوجد مدير بعد:

```powershell
npm run setup-admin
```

سيطلب اسم المدير وPIN من 4 إلى 8 أرقام.

ثم شغّل:

```powershell
npm start
```

يجب أن يظهر:

```text
Ward Cafe: http://localhost:3000
```

## 3. اختبار الاتصال

افتح:

```text
http://localhost:3000/api/health
```

ثم:

```text
http://localhost:3000/login.html
```

الدخول للموظفين يتم بواسطة PIN فقط.

## 4. فتح النظام على أجهزة المقهى

اعرف IPv4 للكمبيوتر الرئيسي:

```powershell
ipconfig
```

إذا كان مثلًا `192.168.1.10`:

- المدير: `http://192.168.1.10:3000/admin`
- الكاشير: `http://192.168.1.10:3000/pos`
- المحاسب: `http://192.168.1.10:3000/accounting`
- الجرسون: `http://192.168.1.10:3000/waiter`
- المطبخ: `http://192.168.1.10:3000/kitchen`
- الزبون للطاولة 1: `http://192.168.1.10:3000/index.html?table=1`

إذا لم يفتح النظام من التابلت، اسمح لـ Node.js أو المنفذ TCP 3000 في Windows Firewall للشبكة الخاصة.

## 5. الأدوار

- مدير: إدارة المنيو والموظفين والوصول لباقي صفحات العمل.
- كاشير: نقطة البيع وشاشة الجرسون عند الحاجة.
- محاسب: المحاسبة.
- جرسون: الطلبات الجاهزة والطاولات.
- مطبخ: تجهيز الطلبات.

## 6. اختبار سريع

1. المدير ينشئ كاشير وجرسون ومطبخ ويعطي كل موظف PIN.
2. الكاشير يفتح طاولة ويرسل طلبًا.
3. المطبخ يضغط «تم تجهيز الطلب».
4. الجرسون يضغط «تم التوصيل».
5. الكاشير يحصّل الحساب.
6. المحاسبة تعرض البيع.

MySQL هو المصدر الرسمي للبيانات، والدفع وتغيير حالة الطلب وإغلاق اليوم تتم في الخادم.
